# ГИСТОЛОГИЯ · Орган зрения — Глаз (bulbus oculi)
*Конспект в формате Корнелла*

---

## Общий план строения глаза

| Вопросы / ключевые слова | Конспект |
|---|---|
| Из каких оболочек состоит глазное яблоко? | Глаз имеет **3 оболочки**: 1) фиброзная (наружная) — склера + роговица; 2) сосудистая (средняя, увеальный тракт) — собственно сосудистая оболочка + ресничное тело + радужка; 3) сетчатая (внутренняя) — сетчатка (ретина). |
| Что находится внутри глазного яблока? | Светопреломляющие (диоптрические) среды: роговица, водянистая влага передней и задней камер, хрусталик, стекловидное тело. |
| Откуда развивается каждая оболочка? | Фиброзная и сосудистая — из мезенхимы; сетчатка — из нейроэктодермы (вырост стенки промежуточного мозга — глазной пузырь → глазной бокал); хрусталик — из эктодермы (хрусталиковая плакода). |
| Функциональное деление глаза | Диоптрический аппарат (преломление света) + рецепторный аппарат (сетчатка) + аккомодационный аппарат (хрусталик, ресничное тело, связка) + вспомогательный аппарат (веки, мышцы, слёзные железы). |

## 1. Фиброзная оболочка

| Вопросы / ключевые слова | Конспект |
|---|---|
| Склера — строение | Непрозрачная, плотная оформленная волокнистая соединительная ткань (коллагеновые пучки + эластические волокна + фиброциты). Функция — опорная (каркас глаза), место прикрепления глазодвигательных мышц. |
| Роговица — 5 (6) слоёв | 1. **Передний многослойный плоский неороговевающий эпителий** (регенерирует, много нервных окончаний — высокая чувствительность); 2. **Передняя пограничная мембрана (боуменова)** — гомогенная, без клеток; 3. **Собственное вещество роговицы (строма)** — упорядоченные коллагеновые пластинки + фиброциты, между ними основное вещество, обеспечивающее прозрачность (регулярность расположения фибрилл); 4. **Задняя пограничная мембрана (десцеметова)** — эластичная, продукт эндотелия; 5. **Задний эпителий (эндотелий)** — однослойный плоский, регулирует гидратацию стромы (насосная функция) → поддержание прозрачности. |
| Почему роговица прозрачна? | Отсутствие сосудов, строгая упорядоченность коллагеновых фибрилл (одинаковый диаметр и расстояние), постоянная степень гидратации (регулируется эндотелием). |
| Граница склеры и роговицы | Лимб — переходная зона, здесь располагается трабекулярный аппарат и шлеммов канал (венозный синус склеры) — отток водянистой влаги. |

## 2. Сосудистая оболочка (увеальный тракт)

| Вопросы / ключевые слова | Конспект |
|---|---|
| Собственно сосудистая оболочка (хориоидea) — слои | 1. Надсосудистая пластинка (рыхлая соед. ткань, меланоциты); 2. Сосудистая пластинка (крупные сосуды + меланоциты); 3. Сосудисто-капиллярная пластинка (хориокапилляры — питание наружных слоёв сетчатки, в т.ч. фоторецепторов); 4. Базальная пластинка (мембрана Бруха) — граница с пигментным эпителием сетчатки. |
| Функция сосудистой оболочки | Трофика сетчатки (особенно палочек и колбочек), поглощение избытка света меланоцитами (предотвращение рассеивания). |
| Ресничное (цилиарное) тело — строение | Утолщённая часть сосудистой оболочки. Ресничная мышца (гладкая, 3 пучка: меридиональный, радиальный, циркулярный) — отвечает за аккомодацию. Ресничные отростки покрыты двухслойным эпителием (пигментный + непигментный) — непигментный слой секретирует **водянистую влагу**. |
| Ресничный поясок (цинновы связки) | Волокна от непигментного эпителия к капсуле хрусталика — удерживают хрусталик, передают тягу ресничной мышцы. |
| Радужка — слои | Спереди назад: 1) передний эпителий (продолжение эндотелия роговицы); 2) наружный пограничный слой (фибробласты, меланоциты); 3) сосудистый слой (рыхлая ткань + сосуды); 4) внутренний пограничный слой; 5) пигментный эпителий (2 слоя, продолжение сетчатки — «слепая» часть). |
| Мышцы радужки | Сфинктер зрачка (циркулярный, парасимпатическая иннервация) и дилататор зрачка (радиальный, миоэпителиальные клетки, симпатическая иннервация) — регуляция диаметра зрачка. |
| Цвет радужки | Определяется количеством меланоцитов в строме — чем больше пигмента, тем темнее цвет. |

## 3. Сетчатка (сетчатая оболочка) — самая сложная часть

| Вопросы / ключевые слова | Конспект |
|---|---|
| Из чего развивается сетчатка? | Из глазного бокала (вырост нервной трубки) — наружный листок → пигментный эпителий; внутренний листок → собственно сетчатка (нейральная часть, 9 слоёв). |
| 10 слоёв сетчатки (снаружи внутрь, от сосудистой оболочки) | 1. Пигментный эпителий; 2. Слой палочек и колбочек (наружные и внутренние сегменты фоторецепторов); 3. Наружная пограничная мембрана; 4. Наружный ядерный слой (тела фоторецепторов); 5. Наружный сетчатый (плексиформный) слой (синапсы фоторецепторов с биполярами); 6. Внутренний ядерный слой (тела биполярных, горизонтальных, амакринных клеток, клеток Мюллера); 7. Внутренний сетчатый слой (синапсы биполяров с ганглиозными клетками); 8. Ганглионарный слой (тела ганглиозных клеток); 9. Слой нервных волокон (аксоны ганглиозных клеток → зрительный нерв); 10. Внутренняя пограничная мембрана. |
| Пигментный эпителий — функции | Поглощение света (меланин), фагоцитоз отработанных дисков наружных сегментов фоторецепторов, участие в цикле ретиналя (зрительный пигмент), барьер (гемато-ретинальный), транспорт метаболитов из хориокапилляров. |
| Палочки vs колбочки | **Палочки**: длинный тонкий наружный сегмент, диски отделены от плазмолеммы, пигмент — родопсин, сумеречное/чёрно-белое зрение, высокая чувствительность, много (~120 млн). **Колбочки**: короткий конический сегмент, полудиски — впячивания плазмолеммы, пигмент — йодопсин (3 вида), дневное/цветовое зрение, меньше (~6-7 млн), сосредоточены в жёлтом пятне. |
| Строение фоторецептора (общее) | Наружный сегмент (диски с пигментом) — связующий отдел (ресничка, 9х2+0) — внутренний сегмент (митохондрии, синтетический аппарат) — ядро — синаптическая ножка. |
| Жёлтое пятно (macula lutea) и центральная ямка (fovea centralis) | Место наилучшего видения — только колбочки, остальные слои сетчатки истончены/сдвинуты в стороны для облегчения доступа света. |
| Слепое пятно | Диск зрительного нерва — место выхода аксонов ганглиозных клеток, фоторецепторов нет. |
| Нейронный состав сетчатки (3 нейрона зрительного пути) | 1) Фоторецепторный (палочки/колбочки) → 2) биполярный → 3) ганглиозный. Горизонтальные и амакринные клетки — вставочные, обеспечивают латеральное торможение/модуляцию сигнала. |
| Глиальные клетки сетчатки | Клетки Мюллера (радиальная глия, пронизывают всю толщу сетчатки, формируют пограничные мембраны, опорная и трофическая функция). |

## 4. Светопреломляющие (диоптрические) среды

| Вопросы / ключевые слова | Конспект |
|---|---|
| Хрусталик — строение | Капсула (базальная мембрана, толстая, эластичная) → субкапсулярный эпителий (однослойный кубический, только на передней поверхности, зона роста на экваторе) → хрусталиковые волокна (вытянутые, безъядерные, заполнены белком кристаллином, плотно упакованы). |
| Особенности хрусталика | Не имеет сосудов и нервов, питание — диффузно из водянистой влаги; растёт всю жизнь за счёт эпителия экватора (новые волокна наслаиваются, старые уплотняются в ядро). |
| Аккомодация — механизм | Сокращение ресничной мышцы → расслабление цинновых связок → хрусталик становится более выпуклым (эластичность капсулы) → усиление преломления для близких предметов. |
| Стекловидное тело | Прозрачный гель: коллаген II типа + гиалуроновая кислота + гиалоциты (немногочисленные клетки). Заполняет полость между хрусталиком и сетчаткой, поддерживает форму глаза и прижимает сетчатку. |
| Водянистая влага | Продуцируется непигментным эпителием ресничных отростков → задняя камера → через зрачок → передняя камера → отток через угол передней камеры (трабекулярная сеть, шлеммов канал). Питание роговицы и хрусталика, поддержание внутриглазного давления. |

## 5. Вспомогательный аппарат глаза

| Вопросы / ключевые слова | Конспект |
|---|---|
| Веки — слои | Кожа → подкожная клетчатка → круговая мышца глаза (поперечно-полосатая) → хрящевая пластинка (плотная соед. ткань, не гиалиновый хрящ) с мейбомиевыми (тарзальными) железами (сальные, секрет — липидный слой слёзной плёнки) → конъюнктива (многослойный призматический/переходный эпителий с бокаловидными клетками). |
| Ресницы и их железы | У корня ресниц — сальные железы Цейса и видоизменённые потовые железы Молля. |
| Слёзная железа — тип | Сложная альвеолярно-трубчатая серозная железа; секрет — слёзная жидкость (лизоцим — бактерицидное действие). |
| Слёзная плёнка — 3 слоя | Наружный липидный (мейбомиевы железы, снижает испарение), средний водянистый (слёзная железа), внутренний муциновый (бокаловидные клетки конъюнктивы, обеспечивает смачивание роговицы). |
| Конъюнктива | Многослойный (местами переходный) эпителий с бокаловидными клетками (слизь) на собственной пластинке рыхлой соединительной ткани; покрывает веки изнутри и склеру. |

## Итоговое резюме (Summary)

Глаз построен по принципу **трёх оболочек** (фиброзная → сосудистая → сетчатая), окружающих **три светопреломляющие среды** (роговица, хрусталик, стекловидное тело + водянистая влага камер). Каждая оболочка выполняет свою функцию: фиброзная — опора и первичное преломление (роговица), сосудистая — трофика и регуляция (аккомодация через ресничное тело, диаметр зрачка через радужку), сетчатка — фоторецепция и первичная обработка сигнала через цепь из **трёх нейронов** (фоторецептор → биполяр → ганглиозная клетка) с латеральной модуляцией горизонтальными и амакринными клетками. Прозрачность оптических сред (роговица, хрусталик, стекловидное тело) обеспечивается отсутствием сосудов и строгой молекулярной/фибриллярной организацией. Вспомогательный аппарат (веки, слёзная железа, конъюнктива) защищает и увлажняет поверхность глаза.

**Ключевая логика для экзамена:** для каждой структуры называть — (1) из какого зародышевого листка развивается, (2) из каких слоёв/клеток состоит, (3) какую функцию выполняет — это покрывает 90% вопросов Афанасьева по теме.
