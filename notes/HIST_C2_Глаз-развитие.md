# ГИСТОЛОГИЯ · Развитие органа зрения (эмбриогенез глаза)
*Конспект в формате Корнелла*

| Вопросы / ключевые слова | Конспект |
|---|---|
| Из каких источников развивается глаз? (3 источника) | 1) **Нейроэктодерма** (стенка промежуточного мозга) → сетчатка, пигментный эпителий, зрительный нерв; 2) **Кожная эктодерма** → хрусталик, эпителий роговицы, эпителий конъюнктивы; 3) **Мезенхима** (частично нервного гребня, частично мезодерма) → склера, строма роговицы, сосудистая оболочка, строма радужки, стекловидное тело (частично). |
| Шаг 1 — глазные пузыри | На стадии нейрулы боковые стенки промежуточного мозга образуют парные выпячивания — **глазные пузыри** (на ножке — будущий зрительный нерв). Растут навстречу поверхностной эктодерме. |
| Шаг 2 — индукция хрусталика | Глазной пузырь, достигнув эктодермы, индуцирует в ней утолщение — **хрусталиковую плакоду**. Плакода впячивается → **хрусталиковая ямка** → отшнуровывается → **хрусталиковый пузырёк** (лежит в полости глазного бокала). |
| Шаг 3 — образование глазного бокала | Под действием впячивающегося хрусталикового пузырька дистальная стенка глазного пузыря вдавливается внутрь → пузырь превращается в **двухслойный глазной бокал** (чашу). Наружный листок — тонкий; внутренний — толстый. |
| Судьба листков глазного бокала | **Наружный листок** (тонкий) → **пигментный эпителий сетчатки** (на всём протяжении, вплоть до радужки и ресничного тела). **Внутренний листок** (толстый) → нейральная часть сетчатки (9 слоёв — фоторецепторы, биполяры, ганглиозные клетки и т.д.) в заднем отделе; в переднем отделе (где нет фоторецепторов) оба листка остаются недифференцированными → эпителий ресничного тела и радужки. |
| Хориоидальная (зрительная) щель | На нижней поверхности глазного бокала и глазного стебелька есть щель, через которую в полость бокала входит мезенхима с **гиалоидной артерией** (питание хрусталика и стекловидного тела на время развития, затем редуцируется). Щель зарастает к концу 2-го месяца — при незарастании → врождённая колобома. |
| Развитие хрусталика | Хрусталиковый пузырёк: клетки задней стенки сильно вытягиваются, теряют ядра, заполняются кристаллином → превращаются в **первичные хрусталиковые волокна** (заполняют полость пузырька). Клетки передней стенки остаются кубическими → **субкапсулярный эпителий**, за счёт которого на экваторе всю жизнь образуются **вторичные волокна** (рост хрусталика продолжается пожизненно). |
| Развитие роговицы | Формируется из 3 источников: передний эпителий — из **поверхностной эктодермы**; строма и задний эпителий (эндотелий) — из **мезенхимы**, врастающей между хрусталиком и эктодермой в несколько волн. |
| Развитие сосудистой и фиброзной оболочек | Мезенхима, окружающая глазной бокал, дифференцируется в 2 слоя: наружный уплотнённый → **склера**; внутренний, богатый сосудами → **сосудистая оболочка** (хориоидea, ресничное тело, строма радужки). |
| Развитие стекловидного тела | Первичное стекловидное тело — мезенхима + гиалоидная артерия в полости глазного бокала; позже замещается **вторичным стекловидным телом** (вырабатывается клетками сетчатки/эпителия — истинное вещество взрослого стекловидного тела), гиалоидная артерия редуцируется (остаётся canalis hyaloideus). |
| Развитие зрительного нерва | Аксоны ганглиозных клеток сетчатки растут по глазному стебельку к мозгу → формируют **зрительный нерв**; полость стебелька облитерируется. |
| Развитие век и слёзного аппарата | Веки — складки эктодермы с мезенхимой внутри, срастаются на время (до ~7 мес.) и затем разделяются; слёзная железа и мейбомиевы железы — производные эктодермальных выростов конъюнктивы/краёв век. |
| Критический период / пороки | Основной органогенез глаза — 3–10 недели эмбриогенеза. Нарушения: колобома (незаращение зрительной щели), катаракта (нарушение волокнообразования хрусталика), анофтальмия/микрофтальмия (дефект глазного пузыря). |

---

## Итоговое резюме

Глаз закладывается как **вырост мозга** (глазной пузырь → глазной бокал → сетчатка + пигментный эпителий + зрительный нерв), который **индуцирует** над собой хрусталик из поверхностной эктодермы, а вокруг себя обрастает мезенхимой, дающей фиброзную и сосудистую оболочки, строму роговицы и частично стекловидное тело. Формула для запоминания источников:

**Нервная трубка → сетчатка/зрит. нерв | Эктодерма → хрусталик, эпителий роговицы | Мезенхима → всё «опорно-сосудистое» (склера, хориоидea, строма роговицы и радужки, стекловидное тело).**
